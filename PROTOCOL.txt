Exploratory protocol fixed before model evaluation, 2026-10-12.

Question: Does decomposition into individually exact pairwise views preserve the decidability of a joint documentation claim? Can a shared source-row witness interface recover joint support without trusting prose synthesis?

Corpus: 30 preselected widely used Python packages; last 8 stable releases with non-yanked wheel artifacts in a frozen PyPI snapshot. Relations contain (release, interpreter_tag, platform_tag), parsed by packaging.utils.parse_wheel_filename. Pure-Python-only packages yield no CPython-target relations. Claims concern published artifact tags, NOT actual installability, source builds, full ABI compatibility, or transitive dependencies.

Selection: Find absent triples whose three 2-field projections are all present in the same package relation. Select at most 12 per package using seed 1720406, with one supporting row from each pair and 9 randomly selected distractors. Pair each negative with a genuine row in the same context. Selection precedes model calls and uses no model performance. This is an enriched stress test, not a prevalence estimate.

Models: existing local Qwen3-4B-Instruct-2507 4-bit and SmolLM2-1.7B-Instruct at the revisions recorded in prior experiment. No fine tuning or paid API calls. Inference is label-restricted next-token classification A=supported, B=not listed, C=insufficient information. Report label probability conditional on these three tokens; do not call it calibrated confidence. Full-vocabulary top token also logged.

Views: direct rows; exact unkeyed pair projections; exact keyed pair projections. Same claim/reference and corpus across views. Direct and keyed views contain enough information to decide; unkeyed views can be information-losing. Permit abstention. A separate deterministic source-row intersection baseline is checked against independent SQL and exact source files. Do not present a forced bad decomposition as an implementation of FActScore or CARVE.

Primary endpoints: exact support-classification accuracy, false acceptance on unsupported claims, abstention, pair-level both-correct accuracy. Report package-level variation and paired clustered bootstrap by package (stress-test uncertainty only, not deployment prevalence). Treat claim pairs and their views as dependent. Model-generated decomposition and end-to-end content generation are separate experiments required before any paper claim about natural workflow frequency.

Novelty exclusions: relational hallucination and n-ary factuality are established (BeyondAtoms/CARVE, FLEEK, Hyper-RAG); relational lossless joins and provenance are established database theory. Potential contribution is a scoped developer-documentation system and an executable test of witness loss at decomposition interfaces. Novelty not yet established.

Amendment before examining scored model outputs: factual reference agreement counts abstention separately from false decisions. For unkeyed projections, also compute the evidence-relative label across all relations having those projections. A query is possible iff it belongs to their natural join J; it is certain iff removing it from J destroys some supplied projection; otherwise the right evidence-relative answer is C. This avoids treating a justified abstention as a hallucination. The check script records both labels. Exact mathematical construction verified against SQL before reporting model outcomes.

Expedited-completion amendment: the requested rapid wrap-up curtailed the large model sweep. Retain all completed classifications: Qwen3 40 tasks x 3 views, Qwen2.5-Coder 12 tasks x 3 views. Do not infer statistical superiority from these unequal pilots. The free-generation control uses one matched pair per affected package (28 tasks), all 3 views, greedy decoding and a 256-token cap. The natural planner is tested on those same 28 tasks, with a 160-token cap. Its exact JSON field-name schema is scored before interpreting any alternative representation; raw failures are preserved. These exploratory controls do not establish natural decomposition prevalence.
